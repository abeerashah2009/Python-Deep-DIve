## 4. Introduction to Loops

A loop is a programming structure that executes a block of code repeatedly.

Loops are useful when we need to perform the same operation multiple times.

### 4.1 What Is Iteration?

Iteration means repeating a set of instructions.

For example, printing numbers from 1 to 5 requires five iterations.

### 4.2 What Is a Loop Condition?

A loop condition determines whether a loop should continue or stop.

In a while loop, Python checks the condition before each iteration.

### 4.3 Types of Loops in Python

Python provides two commonly used loop structures:

- `for` loop
- `while` loop

## 5. Task 1: Use a For Loop to Print Numbers 1 to 5

### 5.1 Objective

Create a Python program that prints numbers from 1 to 5 using a for loop.

### 5.2 Understanding the For Loop

A for loop iterates over a sequence or another iterable object.

It is useful when the number of iterations is known or when we need to process every item in a collection.

### 5.3 Understanding range()

The `range()` function generates a sequence of numbers.

Syntax:

```python
range(start, stop)
```

Example:

```python
range(1, 6)
```

It generates:

```text
1, 2, 3, 4, 5
```

Important: The ending value 6 is excluded.

### 5.4 Create the Python File

File name:

`for_loop_example.py`

Code:

```python
# Loop through numbers 1 to 5 and print them
for i in range(1, 6):
    print(i)
```

### 5.5 Code Explanation

**Line 1:**

```python
# Loop through numbers 1 to 5 and print them
```

This is a comment explaining the purpose of the program.

**Line 2:**

```python
for i in range(1, 6):
```

- `for` starts the loop.
- `i` is the loop variable.
- `range(1, 6)` generates numbers from 1 to 5.
- The colon `:` starts the loop body.

**Line 3:**

```python
print(i)
```

Prints the current value of `i`.

Python repeats this statement for every value generated by `range()`.

### 5.6 Execute the Program

Command:

```bash
python3 for_loop_example.py
```

Expected output:

```text

2
3
4
5
```

### 5.7 Verify the Last Printed Number

Command:

```bash

```

Output:

```text

```

Explanation:

- `|` is a pipe that sends the output of one command to another.
- `tail` displays the ending lines.
- `-1` displays only the last line.

**Result:** The for loop successfully printed numbers from 1 to 5.

## 6. Task 2: Use a While Loop to Sum Numbers Until Total Exceeds 20

### 6.1 Objective

Create a Python program that repeatedly adds numbers until the total becomes greater than 20.

### 6.2 Understanding the While Loop

A while loop executes a block of code as long as its condition remains `True`.

It is useful when the number of iterations is not known in advance and execution depends on a condition.

### 6.3 Create the Python File

File name:

`while_loop_example.py`

Code:

```python
# Initialize variables
total = 0
i = 1

# Continue summing until the total exceeds 20
while total <= 20:
    total += i
    i += 1

print("Final total:", total)
```

### 6.4 Code Explanation

**Step 1: Initialize the total**

```python
total = 0
```

The variable `total` stores the cumulative sum.

It starts at zero.

**Step 2: Initialize the loop variable**

```python
i = 1
```

The variable `i` stores the current number to be added.

It starts at one.

**Step 3: Set the while condition**

```python
while total <= 20:
```

The loop continues while the total is less than or equal to 20.

When the total becomes greater than 20, the condition becomes false and the loop stops.

**Step 4: Update the total**

```python
total += i
```

This is a shorthand for:

```python
total = total + i
```

It adds the current value of `i` to `total`.

**Step 5: Increment the loop variable**

```python
i += 1
```

This is a shorthand for:

```python
i = i + 1
```

It increases the value of `i` by one for the next iteration.

**Step 6: Display the final result**

```python
print("Final total:", total)
```

Displays the final cumulative sum after the loop terminates.

### 6.5 Understanding the Loop Execution

| Iteration | Current i | Total after addition |
|---|---:|---:|
| 1 | 1 | 1 |
| 2 | 2 | 3 |
| 3 | 3 | 6 |
| 4 | 4 | 10 |
| 5 | 5 | 15 |
| 6 | 6 | 21 |

At the end of iteration 6:

```text
total = 21
```

The condition becomes:

```python
21 <= 20
```

This is `False`, so the loop terminates.

### 6.6 Execute the Program

Command:

```bash
python3 while_loop_example.py
```

Output:

```text
Final total: 21
```

**Result:** The while loop successfully calculated the sum and stopped when the total exceeded 20.

## 7. Task 3: Differences Between For and While Loops

Both loops repeat instructions, but they are suitable for different situations.

### 7.1 For Loop

A for loop is generally used when iterating over a sequence or when the number of iterations is known.

Examples:

- Printing a fixed range of numbers.
- Processing items in a list.
- Reading elements from a collection.
- Processing a fixed number of records.

Example:

```python
for i in range(1, 6):
    print(i)
```

### 7.2 While Loop

A while loop is used when repetition depends on a condition.

Examples:

- Checking whether a service is available.
- Waiting for a condition to become true.
- Reading data until the end of a file.
- Repeating an operation until a target is reached.

Example:

```python
total = 0
i = 1

while total <= 20:
    total += i
    i += 1

print("Final total:", total)
```

### 7.3 Comparison Table

| Aspect | For Loop | While Loop |
|---|---|---|
| Iteration count | Often known in advance | Depends on a condition |
| Typical input | Sequence or range | Boolean condition |
| Execution | Iterates over items | Runs while condition is true |
| Variable update | Often handled by iteration | Usually managed manually |
| Lab example | Print 1 to 5 | Sum until total exceeds 20 |
| Lab result | Last line 5 | Final total 21 |

## 8. Common Mistakes and Troubleshooting

### 8.1 Forgetting the Colon

Incorrect:

```python
for i in range(1, 6)
    print(i)
```

Correct:

```python
for i in range(1, 6):
    print(i)
```

A colon is required after the loop statement.

### 8.2 Incorrect Indentation

Incorrect:

```python
while total <= 20:
total += i
```

Correct:

```python
while total <= 20:
    total += i
```

Python uses indentation to identify the statements inside a loop.

### 8.3 Forgetting to Update the Loop Variable

Example:

```python
i = 1

while i <= 5:
    print(i)
```

This creates an infinite loop because `i` never changes.

Correct:

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

### 8.4 Incorrect Range Ending

```python
range(1, 5)
```

This produces numbers 1 through 4, not 1 through 5.

Correct:

```python
range(1, 6)
```

## 12. Interview Questions and Answers

### Q1. What is a loop in Python?

A loop is a programming structure used to execute a block of code repeatedly.

### Q2. What are the two main types of loops in Python?

The two main types are for loops and while loops.

### Q3. What is a for loop?

A for loop iterates over a sequence or iterable object.

### Q4. What is a while loop?

A while loop executes repeatedly as long as its condition is true.

### Q5. What is iteration?

Iteration is one execution of the loop body.

### Q6. What does range(1, 6) generate?

It generates the numbers 1, 2, 3, 4 and 5. The ending value 6 is excluded.

### Q7. What is an infinite loop?

An infinite loop is a loop that continues running because its termination condition never becomes false.

### Q8. How can an infinite while loop be prevented?

Make sure the loop condition can eventually become false and update the relevant variables correctly.

### Q9. What does total += i mean?

It means:

```python
total = total + i
```

### Q10. When should we use a for loop instead of a while loop?

Use a for loop when iterating over a sequence or when the number of iterations is known.
